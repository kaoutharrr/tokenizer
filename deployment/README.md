# Kaou42 Deployment

## Requirements

- Remix IDE
- MetaMask wallet
- Sepolia test ETH
- Solidity compiler compatible with `^0.8.20`
- OpenZeppelin Contracts 5.4.0

## Steps

1. Open Remix IDE.
2. Import `code/Kaou42Token.sol`.
3. Compile the contract using a compatible Solidity compiler.
4. Test deployment using Remix VM.
5. Connect MetaMask to Ethereum Sepolia.
6. Select the injected wallet provider in Remix.
7. Deploy `Kaou42Token`.
8. Confirm the transaction in MetaMask.
9. Record the contract address and transaction hash.
10. Verify the contract source on Sepolia Etherscan.



## Verification

Verify the contract using the same source code, dependency version, compiler version and optimization settings used during deployment.
